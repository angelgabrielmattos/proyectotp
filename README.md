# Character Counter

## Objetivo del proyecto

El objetivo de este proyecto fue replicar la interfaz de una pagina web utilizando únicamente HTML y CSS, sin implementar funcionalidades con JavaScript, con la idea de potenciar los conocimientos.

## Tecnologías utilizadas

- HTML
- CSS

## Organización del HTML

La estructura HTML fue desarrollada utilizando etiquetas semánticas, de igual manera a medida que se iba avanzando en el proyecto se fueron realizando distintas modificaciones en la estructura:

- body
- h1
- textarea
- div
- label
- input
- h2 / h3 
- img
- p
- span

## Resolución del CSS

Se utilizó tanto Flexbox como Grid para la distribución de elementos y para las tarjetas de métricas, a su ves para buscar cierta especificidad en algun elemento, se ha llegado a usar pseudo-clases, tambien se aprovechado la herramiente de root: para buscar comodidad a la hora de trabajar con los colores


## Dificultades encontradas

- Replicar el diseño original.
- Volver a reestructurar html por complicaciones en CSS.
- Implementar las barras de progreso.
- Simetria en los elementos.
